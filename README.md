# Čeština k maturitě – procvičování

Interaktivní procvičování češtiny k maturitě (časová osa, spojovačka, figury, kvíz, kartičky, křížovka…).

**Otevřít:** stačí otevřít `index.html` v prohlížeči, nebo odkaz na GitHub Pages.

- Funguje na mobilu, iPadu i počítači, bez internetu.
- Obsah pochází z jednoho zápisu z hodin. Položky označené **doplněno** v původním zápisu nebyly.
- Postup se ukládá jen ve tvém prohlížeči.
